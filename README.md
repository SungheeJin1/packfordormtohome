# packfordormtohome

기숙사 → 집 짐싸기 3D 게임.

1. **짐 리스트**: 가져갈 짐 이름을 체크리스트로 적어요. 각 짐이 가방에서 어떤 3D 모양으로 보일지 옆에 표시돼요.
2. **가방 싸기**: "리스트 작성 완료"를 누르면 3D 가방 화면으로 넘어가요. 챙긴 짐 이름을 입력하거나 체크하면 그 물건(옷, 청바지, 노트북, 칫솔…)이 3D로 가방 안에 떨어져요. 모양을 모르는 짐은 이름표가 붙은 상자로 들어가요.
3. 전부 넣으면 색종이가 터지면서 짐 싸기 완료!

`index.html` 하나로 동작해요 (Three.js r128과 RoundedBoxGeometry, RoomEnvironment를 CDN에서 불러옴). 브라우저로 열거나 GitHub Pages로 배포하면 돼요.
