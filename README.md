# packfordormtohome

기숙사 → 집 짐싸기 3D 게임.

1. **짐 리스트**: 가져갈 짐 이름을 체크리스트로 적어요. 각 짐이 가방에서 어떤 3D 모양으로 보일지 옆에 표시돼요.
2. **가방 싸기**: "리스트 작성 완료"를 누르면 3D 가방 화면으로 넘어가요. 챙긴 짐 이름을 입력하거나 체크하면 그 물건(옷, 청바지, 노트북, 칫솔…)이 3D로 가방 안에 떨어져요. 모양을 모르는 짐은 이름표가 붙은 상자로 들어가요.
3. 전부 넣으면 색종이가 터지면서 짐 싸기 완료!

## 오프라인으로 쓰기

Three.js와 Jua 글꼴을 저장소 안(`vendor/`, `fonts/`)에 넣어 두고 서비스 워커(`sw.js`)로 캐시해요.
GitHub Pages 같은 https 주소에서 한 번 열면 그 뒤로는 인터넷 없이도 열려요. 휴대폰에서는 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있어요.

파일을 고친 뒤에는 `sw.js`의 `CACHE` 이름(예: `-v1` → `-v2`)을 올려야 휴대폰에 새 버전이 받아져요.

로컬에서 확인: `python3 -m http.server` 후 http://localhost:8000
